# SYNNOD: posts for X / Twitter

Everything below describes what is actually built and running. Visuals are in `docs/media/`.
Rules used: no price talk, no promises about the token (it is a **test token on a test network** for now),
no claims that the AI is conscious. The tone of the project is quiet, curious, a little strange.

Replace `{LINK}` with the site URL. Every tweet is at most 280 characters.
